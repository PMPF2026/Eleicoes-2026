Mapa Eleitoral dos municípios do Rio Grande do Sul

Sobre o projeto

O WebGIS apresenta informações eleitorais dos 497 municípios do Rio Grande do Sul, permitindo visualizar espacialmente os resultados para os cargos de Presidente da República e Governador do Estado.

Os dados eleitorais são atualizados automaticamente durante a apuração, conforme a disponibilização de novos resultados oficiais.

Fonte dos dados

Tribunal Superior Eleitoral — TSE

Os dados eleitorais utilizados pelo sistema são provenientes das bases oficiais disponibilizadas pelo Tribunal Superior Eleitoral.

A atualização é realizada automaticamente por uma esteira de coleta e consolidação de dados, preservando os dados anteriormente válidos quando determinada informação ainda não apresenta atualização.

Fonte oficial dos dados eleitorais — Tribunal Superior Eleitoral (TSE)

Base cartográfica

A representação espacial utiliza a malha municipal do Rio Grande do Sul, composta pelos 497 municípios, vinculada aos dados eleitorais por meio do código oficial do município.

A vinculação eleitoral/cartográfica utiliza o código IBGE do município, evitando associação por nome.

Finalidade

O sistema foi desenvolvido para facilitar a visualização espacial, consulta e análise dos resultados eleitorais municipais, permitindo observar a distribuição territorial dos resultados e comparar diferentes municípios durante o processo de apuração.

Atualização dos Dados

Os dados são atualizados automaticamente conforme novos resultados são disponibilizados pelo TSE.
